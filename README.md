# 集团固定资产管理系统

Nuxt3 + Element Plus + UnoCSS + Nitro + Prisma + SQLite（本地）一体化单仓库中后台系统。
低并发、单机 PM2 部署、不引入重型组件、按模块迭代交付，每次只输出当前模块代码。

## 已实现功能

**M1 基础权限**
- 登录（JWT + httpOnly Cookie）、退出、登录态 SSR 水合、未登录自动跳转
- RBAC：角色→权限点（菜单/按钮）+ 数据范围（ALL 全部 / ORG 本组织 / DEPT 本部门 / SELF 仅本人，多角色取最宽）
- 用户 / 角色（权限树分配）/ 组织架构 / 操作日志 四套管理页面

**M2 资产台账**
- 资产分类：多级树、使用年限（折旧用）、删除保护（有子分类或资产时禁止删除）
- 资产卡片：编号自动生成（ZC+日期+序号）、分类/规格/品牌/状态/所属公司/使用部门/使用人/存放地点/购置日期/原值/累计折旧/净值/供应商/发票号
- 查询：关键字、分类（含子分类）、状态、所属公司、购置日期区间；台账概览（总数/在用/在库/原值合计/净值合计）
- Excel 导出：按当前筛选条件导出（表头样式 + 金额格式 + 冻结首行）

**M3 资产生命周期（流转）**
- 流转类型：入库 IN / 领用 ISSUE / 归还 RETURN / 调拨 TRANSFER
- 领用：仅「在库」资产可领用，指定使用人/使用部门后置为「在用」
- 归还：仅「在用」资产可归还，置回「在库」并清空使用人
- 调拨：支持同公司调部门/换使用人，也支持跨公司调拨（跨公司仅超级管理员，调拨后部门与使用人清空待重新指定）
- 批量：一次可对多件资产发起同一流转，服务端事务保证状态与流水一致
- 流转记录页：按类型/关键字/日期区间查询，展示「原归属 → 新归属（公司/部门/使用人）」文本
- 台账页每行「流转」按钮可直接查看该资产的完整流转履历
- 新增资产自动写入一条「采购入库」流水；状态与使用人强一致（无使用人不会停留在「在用」）

**M4 资产盘点**
- 盘点单：单号自动生成（PD+日期+序号）、名称、范围（公司/部门/分类，分类含子分类）、负责人、状态（进行中/已完成）、备注
- 明细快照：创建盘点单时按范围把资产的**账面信息**（状态/归属/使用人/存放地点）快照进明细，执行期间资产变动不影响盘点口径
- 结果录入：逐条下拉录入或勾选批量标记，结果分为 待盘 / 正常 / 盘亏 / 损坏，可填盘点备注
- 进度与差异：列表页显示盘点进度条与盘亏/损坏数量；详情页 6 张统计卡（应盘/已盘/待盘/正常/盘亏/损坏）
- 完成与锁定：存在未盘项时不允许完成；完成后明细锁定不可再改，可「重新开启」
- 导出：盘点明细 Excel（盘亏标红、损坏标橙，冻结首行）
- 已报废/已处置资产不纳入盘点范围

**视觉规范**
- 参考 Art Design Pro（Vue3 + Element Plus 中后台模板）的设计语言重做整体 UI
- 主色 `#5D87FF`、页面底 `#fafbfc`、卡片底 `#ffffff`、分割线 `#e2e8ee`、组件高 36px、圆角 6/8/12px
- 侧边栏：品牌渐变图标 + 圆角菜单项（选中态品牌色浅底 + 品牌色文字/图标），**各级菜单均带图标**
- Element Plus 精修：弹窗/下拉/表格/标签/输入框/分页统一圆角与阴影；表格去竖线、浅色表头
- 设计令牌集中在 `assets/css/main.css` 的 `:root`，改一处即可换肤


## 本地启动

```bash
npm install
npm run db:reset   # 建表 + 初始化数据（首次）
npm run dev        # http://localhost:3000
```

## 生产部署（PM2）

```bash
npm run build
pm2 start ecosystem.config.cjs
```

```

├── pages/             # login、工作台、asset（台账·分类·流转·盘点）、system（用户·角色·组织·日志）

├── assets/css/        # 基础样式
├── ecosystem.config.cjs  # PM2 配置

```

## 权限模型

- 功能权限：角色 → 权限点（MENU 菜单 / BUTTON 按钮），SUPER_ADMIN 自动拥有全部
- 数据权限：角色 dataScope = ALL / ORG / DEPT / SELF，多角色取最宽范围
- 操作日志：所有写操作自动落库，可在「操作日志」页查询
