## 二、优化清单

### 2.1 设计令牌与色彩系统（`assets/css/main.css`）

**核心问题**：Element Plus 由 `@element-plus/nuxt` **运行时注入样式**，其注入时机晚于 `main.css`；当选择器特异性相同时 EP 胜出，导致 `:root` 上的变量覆盖**静默失效**——这正是首轮 axe 仍报 `#409eff`(2.78:1)、占位符 `#a8abb2`(2.29:1)、表头 `#909399`(2.94:1) 的原因。

**解法**：所有覆盖选择器提升为 `html:root`（特异性 0,2,1 > EP 的 0,1,0）。

| 令牌 | 值 | 用途与依据 |
|------|-----|-----------|
| `--brand` | `#5d87ff` | 大面积强调（选中态、进度、图标） |
| `--brand-strong` | `#3a5ccc` | 实底按钮 / 链接文字（对白字 5.86:1） |
| `--text-1 / 2 / 3` | `#1f2937` / `#4b5563` / `#5f6b85` | 三级文本，对白底 14.68 / 7.56 / 5.35:1 |
| `--border` | `#e2e8ee` | 表格线、分割线等**装饰性**边框 |
| `--border-control` | `#8a93a6` | **表单控件**边框，对白底 3.09:1（新增） |
| `--success/warning/danger/info-text` | `#146c34` / `#a04a08` / `#b91c1c` / `#5f6b85` | 配浅底标签，均 ≥ 4.85:1 |
| `--focus-ring` | `2px solid #3a5ccc` | 键盘焦点环，对白底 5.86:1 |

**逐项覆盖的 EP 默认缺陷**：

| EP 默认 | 对比度 | 覆盖后 |
|---------|--------|--------|
| 主色 `#409eff` + 白字 | 2.78:1 ✗ | `#3a5ccc` + 白字 = 5.86:1 ✓ |
| 占位符 `#a8abb2` | 2.29:1 ✗ | `--text-3` = 5.35:1 ✓ |
| 表头文字 `#909399` | 2.94:1 ✗ | `--text-2` = 7.23:1 ✓ |
| 表单边框 `#dcdfe6` | 1.33:1 ✗ | `--border-control` = 3.09:1 ✓ |
| 警告标签 `#e6a23c` | 2.1:1 ✗ | 深字浅底（`#a04a08` on `#fdf3e3` = 5.49:1）✓ |
| 实底按钮 `--brand` + 白字 | 3.29:1 ✗ | `--brand-strong` + 白字 = 5.86:1 ✓ |

> **可回退项**：`--border-control: #8a93a6` 是为满足 WCAG 2.1 SC 1.4.11（非文本对比度）而引入的。相比 EP 默认的浅灰边框，表单输入框描边会明显加深。若视觉上希望回到浅描边，改回 `--border: #e2e8ee` 即可，但会**不再满足 AA**。

### 2.2 语义色误用修正（设计语义）

优化前，中性指标被套上了**状态色**，会传递虚假语义：

| 位置 | 原值 | 问题 | 修正 |
|------|------|------|------|
| 工作台「今日操作」 | `--danger-text` 红点 | 日常操作数被渲染成"危险" | 去掉装饰性圆点 |
| 工作台「组织数量」 | `--warning-text` | 组织数与"警告"无关 | 去掉装饰性圆点 |
| 工作台「角色数量」 | `--success-text` | 角色数与"成功"无关 | 去掉装饰性圆点 |
| 台账「原值合计」 | `--warning-text` | 金额与"警告"无关 | 去掉装饰性圆点 |
| 台账「净值合计」 | `--brand-strong` | 与「资产总数」重复用色 | 去掉装饰性圆点 |
| 盘点执行「盘亏」 | 恒为 `--danger-text` | 计数为 0 时仍显示红色，形成假警报 | 改为「有值才着色」，0 用中性色 |

**确立规则**：统计卡圆点只作**状态图例**——仅当指标映射到业务状态（在用 / 在库 / 正常 / 盘亏 / 损坏）时着色；中性聚合值（总数、金额、计数）不加色。模板以 `v-if="s.color"` 实现。

### 2.3 布局与信息层级

- 统一页头 `.page-head`：`h1` 标题 + 一行说明 + 右侧操作区，替代原先散落的标题写法
- 统一工具条 `.toolbar`：`card-base p-3 mb-3` + 内部控件固定宽度，消除筛选栏被拉满行的问题
- 统计卡 `.stat-grid` / `.stat-card`：语义圆点 + 文字色数字，替代彩色块堆叠
- 登录页重写：双栏（深蓝品牌侧 `#1c2b4a` + 表单侧），去掉渐变与演示文案噪音
- 移除工作台 `el-descriptions` 在窄屏的标签折行（`label-width` 随列数 96px / 120px 自适应）

### 2.4 组件与交互一致性

- 新增 `components/AppMenu.vue`：侧边栏菜单抽为组件，桌面侧栏与移动抽屉共用，`visibleChildren()` 过滤无权限子项
- 新增 `composables/useDict.ts`：集中字典（`ASSET_STATUS` / `FLOW_TYPE` / `INV_RESULT` / `DATA_SCOPE` 等），消除各页硬编码中文映射
- 新增 `composables/useDictionaries.ts`：`useState` 缓存组织 / 部门 / 用户 / 分类字典，`ensure(keys)` 按需拉取，避免重复请求
- `stores/auth.ts`：登录 / 登出时 `useDictionaries().reset()`，防止跨账号字典串味
- 移动端导航抽屉补品牌区，与桌面侧栏视觉一致（同时清掉 `:with-header="false"` 下无效的 `title` 属性）

### 2.5 语义结构与键盘可达性

| 项 | 实现 |
|----|------|
| 文档语言 | `nuxt.config.ts` → `htmlAttrs: { lang: 'zh-CN' }` |

### 3.2 对比度实测（手工计算，WCAG 相对亮度公式）

| 前景 / 背景 | 比值 | 要求 | 判定 |
|-------------|------|------|------|
| 正文 `--text-1` / 卡片白 | 14.68:1 | 4.5:1 | ✓ |

| 表头 `--text-2` / 表头底 `--g-100` | 7.23:1 | 4.5:1 | ✓ |
| 弱化 `--text-3` / 卡片白 | 5.35:1 | 4.5:1 | ✓ |
| 弱化 `--text-3` / 页面底 | 5.16:1 | 4.5:1 | ✓ |
| 白字 / 主色按钮 `--brand-strong` | 5.86:1 | 4.5:1 | ✓ |
| `--success-text` / `--success-bg` | 5.86:1 | 4.5:1 | ✓ |
| `--warning-text` / `--warning-bg` | 5.49:1 | 4.5:1 | ✓ |
| `--danger-text` / `--danger-bg` | 5.66:1 | 4.5:1 | ✓ |
| `--info-text` / `--info-bg` | 4.85:1 | 4.5:1 | ✓ |
| 表单边框 `--border-control` / 白底 | 3.09:1 | 3:1 | ✓ |
| 焦点环 `--brand-strong` / 白底 | 5.86:1 | 3:1 | ✓ |

> **关于 axe 报出的「需人工复核 color-contrast」（每页 11–152 项）**：经逐项定位，**全部**是 Element Plus 表头单元格（`th .cell`），原因是 EP 用 `::before` 伪元素绘制表头底色，axe 无法计算背景故降级为 `incomplete` 而非违规。已手工核验：表头文字 `--text-2` `#4b5563` 对表头底 `--g-100` `#f9fafb` = **7.23:1**，远超 AA。**结论：非真实缺陷。**

## 五、遗留问题与建议

### P1（建议下个迭代修）

1. **表单金额可被改坏** —— 资产编辑未做数值范围 / 精度约束，建议 `el-input-number` + 后端二次校验
2. **关联 id 不校验** —— 新增 / 编辑时传入的 `orgId` / `deptId` / `keeperId` 未验证存在性与归属，建议服务端补校验
3. **列表分页无上限** —— 建议 `size` 上限 100，避免一次拉全表
4. **资产详情数据范围** —— 详情接口未覆盖 `DEPT` 范围（列表已覆盖），存在口径不一致

### P2

5. **帮助与文档缺失**（Nielsen #10）—— 建议加一个「使用说明」入口或关键字段的 `el-tooltip` 说明
6. **工作台信息块降噪** —— 「技术栈 / 数据库 / 部署方式」对业务用户是噪音，建议移入系统设置或仅超管可见
7. **表格横向滚动** —— 台账在 1440px 下需横向滚动，「存放地点」列被截断。建议压缩「操作」列（190px → 150px）或减少一个低价值列

### P3

8. **删除无撤销** —— 目前仅二次确认，可考虑软删除 + 回收站
9. **错误提示未就地定位** —— 表单校验建议改为 `el-form` 的 inline 错误

### 安全遗留（来自 2026-10-14 代码审查，未在本轮处理）

- JWT 弱密钥、登录无限流、Cookie 缺 `secure`、`seed` 默认密码 —— 生产部署前**必须**处理
